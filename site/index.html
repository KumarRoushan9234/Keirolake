What it does

One lake for everything you know.

Spreadsheets, PDFs, notes, web pages, public datasets and offline libraries, searchable together by meaning and keyword.

Ask, and see where the answer came from.

Hybrid search over every collection, answered by a local model first. Every claim links to the passage it came from.

  • Chat history grouped by day, with search
  • Falls back to the web only when you allow it

Build a dataset by talking.

Describe a table or an offline library. Agree the columns, then the model fills the rows from your collections, offline libraries or the web, with a source and a confidence for each.

  • Edit the plan by hand before anything is written
  • Keeps working when you leave the page

Capture from your phone.

Voice notes turned into text on your own computer, photos of pages read by a local vision model, and links saved as readable pages. Share from any Android app.

  • No signal? Captures wait on the phone and send later
  • Installs as an app from the browser

Tables with history and sources.

Every table is real SQL with cell-level sources and a full change history. Save views, ask questions in plain words, export to Excel or PDF.

  • Ten free open-data sources and scrapers built in
  • Read-only SQL, generated or written by hand

Models, quantized and unrestricted.

Pull Ollama models, run quantized GGUF files directly, or use Heretic to remove a model's refusals and import the result, all from the app.

  • Cloud models only within a daily limit you set
  • Zero data retention asked on every web request

For your apps and agents

A data layer with an API you already know.

Point any OpenAI SDK, script or MCP client at your lake.

  1. Turn on the linkServe → Sharing → Anywhere, or keirolake serve --share internet
  2. Make a keyOnly the permissions it needs: read, ask, write, sql, llm
  3. Call it from anywhereEvery call is limited, logged and revocable
from openai import OpenAI

lake = OpenAI(
    base_url="https://<your-link>/v1",
    api_key="klk_...",
)

# A model running on your PC
lake.chat.completions.create(
    model="qwen2.5:7b",
    messages=[{"role": "user", "content": "Hello from my phone"}],
)

# An answer grounded in your own data
lake.chat.completions.create(
    model="lake",
    messages=[{"role": "user", "content": "What's in my pricing notes?"}],
)
# Rows from a table, filtered and sorted
curl -H "Authorization: Bearer klk_..." \
  "https://<your-link>/v1/tables/<id>/rows?where=region:eq:South%20Asia&order=-population&limit=10"

# Search a table by meaning
curl -H "Authorization: Bearer klk_..." \
  "https://<your-link>/v1/tables/<id>/search?q=large%20coastal%20cities"
{
  "mcpServers": {
    "keirolake": {
      "url": "https://<your-link>/mcp",
      "headers": { "Authorization": "Bearer klk_..." }
    }
  }
}

Security

You decide what leaves the machine.

The engine listens only on 127.0.0.1 with a new token every launch, so websites can't reach it.

One folder you own

Back it up, copy it to a drive, or delete it.

Cloud only if you allow it

Nothing reaches the cloud until you add a cloud model, and then only up to a daily cap.

Locked doors

A 10+ character password for every way in, lockout after five wrong tries, rate limits, optional allow-list.

Scoped keys

Per-permission and per-collection, expiring, revocable, stored as hashes, every call logged.

The Vault

AES-256-GCM private notes, locked after 15 idle minutes, only ever sent to local models.

Signed updates

Every release is built and tested in public, and checked against a signature before it installs.
